## 0. 根概念：一切矩阵都是网络参数（最重要）

**Transformer 是一个端到端可训练的神经网络。所有"训练矩阵"（W_q/W_k/W_v/W_o、embedding 表、输出投影）都是这个网络的参数：随机初始化 → 前向 → loss → 反向传播 → 更新。**

- 不存在"另一个机器学习辅助"或"先跑一轮传统 ML"
- 类比：CIFAR-10 里 `model.fc` 的权重 = Transformer 里的 W_q，同类东西
- 训练数据 = (输入序列, 真实下一个词)，loss = 预测 vs 真实的交叉熵

---

## 1. 输入表示

| 组件 | 作用 |
|---|---|
| **Embedding 层** | token id → 512 维向量（查表，表本身是参数，训练得到） |
| **位置编码** | 每个位置一个"指纹"向量，加到 embedding 上（**只加在最底层输入**） |

**为什么需要位置编码**：attention 本身**无序**（打乱输入顺序，attention 输出不变，因为权重只看内容相关性）。位置编码是顺序信息的唯一来源。

---

## 2. 自注意力（Scaled Dot-Product Attention）

**一句定义**：每个位置作为 query，与**所有**位置的 key 算相关性，用相关性加权所有位置的 value。

### 2.1 Q/K/V 是什么

- **Q（Query）**：我在找什么（当前词想关注谁）
- **K（Key）**：我能提供什么标签（让别的词能匹配到我）
- **V（Value）**：实际内容（被加权提取的信息）

检索类比：搜索框输入=Q，文档标题=K，文档正文=V。相关性=q·k，加权取 v。

### 2.2 计算步骤（单头）

```
1. X @ W_q → Q（每行一个词的 query）
2. X @ W_k → K，X @ W_v → V
3. scores = Q @ K^T              # (T,T)：词 i 与词 j 的相关性
4. scores = scores / √d_k        # 防数值过大
5. weights = softmax(scores, dim=-1)
6. out = weights @ V             # 加权求和
```

**为什么除以 √d_k**：d 维向量点积的方差 ∝ d，维度大时数值过大 → softmax 饱和（接近 one-hot）→ 梯度消失。除以 √d 稳定量级。**不是降维**（维度不变）。

**为什么 q 要乘以所有 k**：这是 attention 的定义——每个词都要看其他所有词才能决定自己如何表示（"bank" 需要看到 "river" 才知道是河岸）。

### 2.3 多头注意力

- 单头只能学**一种**加权模式；多头 = 并行学多种关系（语法/句法/指代/长程依赖）
- 实现：d_model 拆成 h 个子空间（每头 d_model/h 维），各头独立计算后**拼接**，再经 W_o 投影回 d_model
- 各头的 W 都是参数，初始随机，**训练后**每头学会关注不同模式

## 3. Encoder 块（Add & Norm + 残差）

每个子层（自注意力 / 前馈网络）后都有：

```
子层输出 = 子层(输入)
输出 = LayerNorm(输入 + 子层输出)   # Add & Norm
```

| 组件 | 作用 |
|---|---|
| **残差（Add）** | 输出 + 输入，梯度直通，解决深层训练难 |
| **LayerNorm（Norm）** | 对每个样本的隐向量归一化（减均值/除标准差 + 可学习 γ/β），稳定分布、训练更稳 |

前馈网络（FFN）：两层全连接 + ReLU，对每个位置独立做非线性变换。

---

## 4. Decoder（自回归）

### 4.1 结构

```
Decoder 输入（已生成的前缀）
  ↓
Masked Self-Attention   ← 只能看自己及之前的 token（causal mask）
  ↓  Add & Norm
Cross-Attention         ← Q 来自 decoder，K/V 来自 encoder 最后一层输出（每层共享同一份 KV）
  ↓  Add & Norm
FFN → Add & Norm
```

### 4.2 Masked Self-Attention 为什么必要

自回归生成：预测第 t 个词时只能看已生成的 1..t-1 个词，**不能偷看未来**。训练时若不禁未来位置，网络会"作弊"直接抄答案。做法：softmax 前把未来位置置 -inf（`torch.triu(ones(T,T), diagonal=1)` 生成上三角掩码）。

### 4.3 为什么多层

每层输入 = 上一层输出，逐层抽象（低层词法 → 高层长程依赖）。与"为什么 ResNet 要 18 层"同类问题。

---

## 5. 输出层与训练

```
隐向量 → 线性层（投影到词表大小）→ softmax → 下一个词的概率分布
```

- **线性层**：把 d_model 维向量映射到词表大小（project = 投影，线性变换）
- **训练**：预测概率 vs 真实下一个词 → 交叉熵 loss → 反向传播更新**所有参数**（embedding、W_q/k/v/o、FFN、输出层）——这就是"训练矩阵哪来的"的答案
- **推理**：逐个词生成（自回归），可用 **beam search**（保留前 k 个候选路径）而非贪心

## 6. 八股速答卡（面试 30 秒版）

| 问题 | 答案要点 |
|---|---|
| Q/K/V 是什么 | Q=查询（当前词关注谁），K=键（被匹配的标签），V=值（实际内容）；相关性=q·k，softmax 后加权 v |
| 为什么 scale | d 大时点积方差大 → softmax 饱和 → 梯度消失；除 √d 稳定 |
| 多头意义 | 并行子空间学多种关系；拼接 + W_o 融合 |
| 位置编码必要 | attention 无序，编码是顺序唯一来源；只加最底层 |
| 残差/归一化 | 梯度直通 + 稳定分布 |
| causal mask | 自回归防作弊，未来位置置 -inf |
| KV cache | 推理时缓存 K/V 避免重复计算（生成第 t+1 词时，前 t 词的 K/V 不变） |
| 复杂度 | 自注意力 O(n²)（每对词都要算相关性）；FlashAttention 用分块+IO 优化 |
| MHA vs GQA | GQA 分组共享 KV，减少 KV cache 内存（推理友好） |
| Pre-Norm vs Post-Norm | Pre-Norm 残差先归一化，训练更稳，现代实现常用 |
