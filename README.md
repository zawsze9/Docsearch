## 项目名称
DocSearch-Service：企业知识智能检索与应用服务（原 DocAgent，2026-08-14 重命名）




## 项目优先级（2026-08-20 修订，6天压缩版以红线为准）
1. **当前红线（8.21–8.26）**：可复现语料版本、BM25/向量/RRF、固定检索评测集、Recall@5/MRR、README 与复现命令；先跑通“检索系统”，再谈服务化。
2. **理想线（红线跑通后才启动）**：rerank、FastAPI、配置/异常处理、pytest、结构化日志、Docker。它们是应用研发证据，但不属于本轮最低交付，不得阻塞 D1–D4。
3. **后续升级线**：Query Rewrite → 意图路由 → 多步检索 → 可追踪引用；必须与单步检索基线对比，顺延至开学后或红线完成后。
4. **有余力**：缓存、超时/重试、调用成本、延迟统计、LLM-as-judge、少量 prompt injection 测试，均不得挤压红线。
5. **暂缓**：LoRA 微调默认第二项目；第二项目优先 LLM4Rec-Lab

## 核心指标口径（防面试追问）
检索质量：Recall@5 / MRR（固定评测集版本，消融：混合 vs 纯向量）
工程：TTFT、P95 延迟、错误率、调用成本
回答质量（有余力时）：LLM-as-judge 三维打分 + 人工抽检一致率
所有实验记录 seed/数据版本/切分/模型版本/硬件
