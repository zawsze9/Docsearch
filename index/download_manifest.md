# DocSearch 语料清单

> 作用：记录“这次索引到底用了哪些文件”。一行代表一个逻辑来源，不需要把 92 个 Markdown 文件逐行手填；文件数量和本地目录负责复核，语料版本负责复现。

## 字段说明

| 字段 | 含义 |
|---|---|
| 来源名称 | 人能看懂的来源名 |
| URL/来源 | 下载地址；本地补充材料写 `local` |
| 快照日期 | 实际复制/下载到本地的日期 |
| 上游 commit | 能确认就写 commit；纯复制快照则注明“参考 commit，未独立校验” |
| 许可证 | 来源仓库的 LICENSE 或内部自有材料 |
| 本地路径 | 相对于 `E:\AI_learning\03_projects\DocSearch\` 的路径 |
| 文件数 | 总文件数与实际纳入索引的 Markdown 数量 |
| 语料版本 | 后续切分、embedding、评测统一引用的版本名 |
| 备注 | 是否包含图片、是否为补充语料、筛选范围等 |

## 复现约定

- 解析脚本只读取上表“本地路径”下的 `.md` 文件，跳过 `.git`、图片、视频和代码文件。
- 任何新增/删除语料都要修改语料版本，并重新记录 Markdown 数量。
- `e6b18cce` 是当前本地完整 clone 的参考 commit；如果以后需要严格复现，应重新从该 commit 导出快照并记录校验值。
